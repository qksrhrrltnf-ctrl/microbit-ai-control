통신 규약

웹앱이 micro:bit로 보내는 것은 줄바꿈으로 끝나는 짧은 문자열 하나뿐입니다.

rock\n
paper\n
stop\n
  • 클래스를 인식하면 매핑 표에서 정한 명령어가 전송됩니다.
  • 인식을 중지하면 항상 stop이 전송됩니다. 이때 모터를 멈추도록 만들어 두세요.
  • UART 한 번에 보낼 수 있는 크기는 20바이트입니다. 명령어는 짧은 영문·숫자로 지으세요.
  • 블루투스 서비스 UUID는 micro:bit 표준 UART 서비스(6E400001-B5A3-F393-E0A9-E50E24DCCA9E)입니다.

⚠️ 먼저 확인할 프로젝트 설정

연결이 안 되는 원인의 대부분이 여기입니다. micro:bit에 프로그램을 넣기 전에 반드시 확인하세요.

  1. No Pairing Required 를 켭니다. 가장 중요한 설정입니다.
    makecode.microbit.org → ⚙️ 톱니바퀴 → 프로젝트 설정 → No Pairing Required: Anyone can connect via Bluetooth 켜기
    이 설정이 꺼져 있으면 연결되자마자 끊어지거나, 기기마다 페어링 절차를 거쳐야 합니다.
  2. 무선(Radio) 블록을 함께 쓸 수 없습니다. 블루투스와 무선은 동시에 사용할 수 없으니 프로젝트에서 무선 블록을 모두 지워주세요.
micro:bit v1은 메모리가 작아 블루투스 + 확장 블록을 여러 개 쓰면 다운로드가 실패할 수 있습니다. 가능하면 v2를 권장합니다.

예제 1 — 기본 수신 (LED로 확인)

MakeCode에서 JavaScript 탭으로 바꾼 뒤 아래 코드를 통째로 붙여넣으면 블록으로도 바뀝니다. 제일 먼저 이걸로 연결이 되는지 확인하세요. 

bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    let command = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))

    if (command == "rock") {
        basic.showIcon(IconNames.Heart)
    } else if (command == "paper") {
        basic.showIcon(IconNames.Square)
    } else if (command == "scissors") {
        basic.showIcon(IconNames.Scissors)
    } else if (command == "stop") {
        basic.clearScreen()
    } else {
        basic.showString(command)
    }
})

bluetooth.startUartService()
basic.showString("BT")
맨 아래 else 덕분에 어떤 명령이 오는지 LED에 그대로 표시됩니다. 매핑을 확인할 때 아주 유용합니다.

예제 2 — 모터 제어 (로봇 움직이기)

인식 결과로 바퀴 로봇을 움직입니다. 핀 번호는 사용하는 보드에 맞게 바꾸세요.

let LEFT = AnalogPin.P1
let RIGHT = AnalogPin.P2

function drive(left: number, right: number) {
    pins.analogWritePin(LEFT, left)
    pins.analogWritePin(RIGHT, right)
}

bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    let command = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))

    if (command == "forward") {
        drive(600, 600)
    } else if (command == "left") {
        drive(0, 600)
    } else if (command == "right") {
        drive(600, 0)
    } else {
        // stop 또는 모르는 명령이면 무조건 정지 (안전)
        drive(0, 0)
    }
})

bluetooth.startUartService()
basic.showString("BT")
안전 팁: 모르는 명령이 오면 멈추도록 else에 정지를 넣어 두세요. 연결이 끊기면 웹앱이 인식을 자동으로 멈추지만, micro:bit는 마지막 명령을 계속 유지하기 때문입니다.

예제 3 — micro:bit가 웹으로 보내기 (양방향)

센서값을 웹앱의 전송 기록에 표시할 수 있습니다. 관찰·실험 수업에 활용해 보세요. 

bluetooth.startUartService()
basic.showString("BT")

basic.forever(function () {
    // 웹앱 기록창에 "light=123" 형태로 표시됨
    bluetooth.uartWriteString("light=" + input.lightLevel() + "\n")
    basic.pause(1000)
})

예제 4 — 사물 위치 받기 (좌표 패킷)

사물인식의 좌표 모드가 보내는 x200y150w080h060n02를 숫자로 나눠 씁니다. 글자 하나 뒤에 숫자가 정해진 자릿수만큼 붙어 있어 substr로 자르면 됩니다. 

// x200y150w080h060n02
//  0123456789...        ← 글자 위치
// x + 3자리, y + 3자리, w + 3자리, h + 3자리, n + 2자리

bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    let command = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))

    if (command == "stop") {
        basic.clearScreen()
        return
    }

    let cx = parseInt(command.substr(1, 3))    // 가로 중심 0~400
    let cy = parseInt(command.substr(5, 3))    // 세로 중심 0~400
    let w = parseInt(command.substr(9, 3))     // 상자 너비
    let h = parseInt(command.substr(13, 3))    // 상자 높이
    let count = parseInt(command.substr(17, 2))// 인식된 개수

    // 사물이 화면 왼쪽/가운데/오른쪽 중 어디에 있는지 LED로 표시
    if (cx < 150) {
        basic.showArrow(ArrowNames.West)
    } else if (cx > 250) {
        basic.showArrow(ArrowNames.East)
    } else {
        basic.showIcon(IconNames.Target)
    }
})

bluetooth.startUartService()
basic.showString("BT")
이름 모드로 바꾸면 person, cup 처럼 영문 이름이 그대로 오므로 예제 1처럼 문자열을 비교하면 됩니다.

예제 5 — 얼굴 값 받기 (얼굴 패킷)

얼굴인식이 보내는 x50y42m30a90b88r5s2를 나눠 씁니다. 위치·입·눈은 2자리, 기울기·미소는 1자리입니다. 

// x50y42m30a90b88r5s2
// x+2 y+2 m+2 a+2 b+2 r+1 s+1

bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    let command = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))

    if (command == "stop") {
        basic.clearScreen()
        return
    }

    let faceX = parseInt(command.substr(1, 2))   // 얼굴 좌우 위치 0~99
    let faceY = parseInt(command.substr(4, 2))   // 얼굴 위아래 위치 0~99
    let mouth = parseInt(command.substr(7, 2))   // 입 벌림 0~99
    let eyeL = parseInt(command.substr(10, 2))   // 왼눈 열림 0~99
    let eyeR = parseInt(command.substr(13, 2))   // 오른눈 열림 0~99
    let roll = parseInt(command.substr(16, 1))   // 고개 기울기 0~9 (5=수평)
    let smile = parseInt(command.substr(18, 1))  // 미소 0~9

    if (mouth > 40) {
        basic.showIcon(IconNames.Surprised)      // 입을 벌리면
    } else if (smile >= 5) {
        basic.showIcon(IconNames.Happy)          // 웃으면
    } else if (eyeL < 30 && eyeR < 30) {
        basic.showIcon(IconNames.Asleep)         // 두 눈을 감으면
    } else {
        basic.showLeds(`
            . . . . .
            . # . # .
            . . . . .
            . . . . .
            . . . . .
            `)
    }
})

bluetooth.startUartService()
basic.showString("BT")

예제 6 — 센서값 보내기 (데이터 스트리머)

데이터 스트리머는 방향이 반대입니다. micro:bit가 보내고 웹이 받아 그래프로 그립니다. 

bluetooth.startUartService()
basic.showString("BT")

basic.forever(function () {
    // 이름=값 형태로 보내면 계열별로 따로 그려집니다.
    // 한 줄에 여러 개를 쉼표로 붙일 수도 있습니다.
    bluetooth.uartWriteString(
        "light=" + input.lightLevel() +
        ",temp=" + input.temperature() + "
")
    basic.pause(200)
})
보내는 간격을 너무 짧게 하면(50ms 이하) 통신이 밀립니다. 200ms 정도가 안정적입니다. 그래프는 계열 4개까지 표시하며, 그 이상은 화면에 알려주고 제외합니다.
