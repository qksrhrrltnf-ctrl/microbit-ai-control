처음 시작하기

micro:bit 준비까지 15분이면 충분합니다.

  1. micro:bit 준비 — micro:bit 코드 안내의 예제를 MakeCode에 붙여넣고 다운로드한 뒤 전원을 켭니다.
    ⚠️ MakeCode 프로젝트 설정에서 No Pairing Required를 켜야 합니다.
    이 설정을 놓치면 연결되자마자 끊어집니다. 연결 문제의 대부분이 이것입니다.
  2. 기능 고르기 — 학습이 필요 없는 사물인식·얼굴인식·음성인식부터 시작하면 가장 빠릅니다.
  3. 직접 학습해보기 — 손모양 학습은 브라우저에서 바로, 이미지·포즈는 Teachable Machine에서 학습한 모델을 불러옵니다.
  4. 연결하고 실행 — 카메라 → 블루투스 → 모델 순서로 진행하고 시작을 누릅니다. micro:bit가 없으면 연습 모드로 먼저 확인하세요.

준비물과 사용 환경

micro:bit 하나와 카메라 달린 기기 하나면 됩니다.

  • micro:bit v1 또는 v2 (블루투스 내장) — 메모리 여유가 있는 v2 권장
  • 카메라·마이크가 있는 기기 — 노트북, 크롬북, 안드로이드 태블릿·폰
  • 브라우저 — Chrome 또는 Edge (Windows / macOS / Android / ChromeOS)
⚠️ iPhone·iPad의 Safari는 Web Bluetooth를 지원하지 않습니다.
iOS에서는 Bluefy 브라우저로 열어주세요. micro:bit가 없어도 연습 모드로 인식 결과와 전송될 명령을 미리 확인할 수 있습니다.
